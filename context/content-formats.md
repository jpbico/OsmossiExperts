# Content formats (from the "Osmossi Content Creation Guide", claude.ai doc, 2026-10-23)

Every post: shoot → ask Claude (in the Osmossi project) → review → finish in Canva → post.
Request template: format · product (name and price) · artisan and origin (only what we know) ·
goal (awareness, engagement, saves, or traffic).

| Format | Size (px) | Length | Best for |
|--------|-----------|--------|----------|
| Feed photo | 1080×1350 (4:5) | — | One hero product shot |
| Carousel | 1080×1350 (4:5), all slides | 2–10 slides | Details, stories, saves |
| Reel | 1080×1920 (9:16) | 7–30 s | Reaching new people |
| Story | 1080×1920 (9:16) | 5–15 s per frame | Daily moments, store links |
| Pinterest Pin | 1000×1500 (2:3) | — | Long-term store traffic |
| Pinterest video Pin | 1080×1920 or 1000×1500 | 6–15 s | Reusing Reels |

- Carousel order: hook → detail close-up → worn/used → artisan or origin → logo + "Shop at osmossi.com".
- Reels: 3–5 s clips, on-screen text for every key moment, end on the logo frame.
- Pins: 2–3 per product, text overlay names a benefit ("Handwoven bag for summer days").
- File names: `osmossi_product_platform_ratio_v1`.

**Before posting:** true-to-life color, size and materials · logo as supplied · text readable and
away from edges · origin facts true · caption, hashtags, alt text · link to osmossi.com ·
Instagram-library music.
