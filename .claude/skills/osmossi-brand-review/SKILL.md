# osmossi-brand-review

Owner agent: `content-studio`. Runs on every draft; nothing reaches Andrea without it.

## Checklist
**Visual**
- [ ] Logo exactly as supplied: not recolored, stretched, cropped or redrawn; enough contrast
- [ ] Colors from the brand kit only (main: Beige Sand `#D6C2A1`, Green `#3E5139`)
- [ ] Fonts: Playfair Display (headlines), Lora (body) only
- [ ] Product color, size, materials true to life; no shape or pattern changes
- [ ] Text minimal, legible on a phone, inside safe zones
- [ ] Right size for the format (`context/content-formats.md`); carousel slides all the same ratio
- [ ] Reels: hook in 1–2 s, on-screen text, logo end frame, music mood noted (Instagram library)

**Words**
- [ ] Voice: casual, enthusiastic, respectful; English with natural Spanish
- [ ] No "one of a kind", "last one", "we make"; Osmossi curates
- [ ] No invented artisan facts or numbers; no stereotypes or clichés
- [ ] No blanket discounts; offers only as approved value offers
- [ ] Up to 2 emojis, elegant; none in Pin titles
- [ ] 3–5 hashtags; alt text present; CTA present
- [ ] Link goes to the product page (or the gift guide), with UTMs

**Facts**
- [ ] Product shown is in stock; price matches the store
- [ ] No other brands' imagery, copyrighted music or characters

## Output
`Brand review: PASS` or `Brand review: FIX` followed by each failed item and the exact fix
(before → after). Fix what you can yourself and re-run before handing to Andrea.
